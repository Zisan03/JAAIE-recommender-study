# Flagging struggling students and recommending learning resources (OULAD): code and results

Code and result files for the manuscript *Flagging Struggling Students and Recommending Learning Resources: A Recent-Popularity List Outperforms Personalized Recommenders in an Offline Evaluation* (draft; add the journal citation and DOI when available).

The scripts reproduce the numbers behind every table and figure from the raw Open University Learning Analytics Dataset (OULAD). The manuscript tables are typed from the CSV files in `results/`; the figures are generated by `make_figures.py`.

## 1. Data (not included in this repository)
OULAD is released by the Open University under **CC BY 4.0** (Kuzilek, Hlosta and Zdrahal, *Scientific Data*, 2017, https://doi.org/10.1038/sdata.2017.171). It is not redistributed here and keeps its own licence.
Download it from https://analyse.kmi.open.ac.uk/open_dataset (mirror: https://archive.ics.uci.edu/dataset/349) and unzip it. The folder must contain
`studentVle.csv`, `vle.csv`, `assessments.csv`, `studentAssessment.csv`, `studentInfo.csv` and `studentRegistration.csv`.
Optional: `python make_study_subset.py PATH_TO_OULAD [output_folder]` writes a small file set containing only the three course presentations used here.

## 2. Run
    pip install -r requirements.txt
    python run_all.py --oulad PATH_TO_OULAD_FOLDER --out results

(On Linux or macOS, `bash run_all.sh PATH_TO_OULAD_FOLDER` does the same.) The run takes several minutes on a laptop; reading the 450 MB click file is the slowest step.
Tested with Python 3.12.3 and the pinned versions in `requirements.txt`. All numeric results are deterministic: a clean run from the raw data reproduced every CSV and `audit.json` in `results/` with identical values, both with the pinned library versions and with newer ones (pandas 3.0.6, numpy 2.5.4, scipy 1.18.1, matplotlib 3.11.2). The three figure files look the same but can differ at the pixel level between matplotlib versions.

## 4. Design settings (in `pipeline.py`)
Courses FFF-2013J, DDD-2013J, CCC-2014J. Cutoff at the 70th percentile of click dates (60 and 80 for robustness). Materials kept if opened by at least 5 training students. Students evaluated if they opened at least 10 training materials and at least 3 new materials after the cutoff. Weak = mean early non-exam assessment score below 55 (50 and 60 as sensitivity). Hybrid weights 0.5/0.5 (0.25 and 0.75 as sensitivity). EASE regularization chosen from {10, 100, 1000, 10000} on a validation split inside the training period. Tie-break seeds 0 to 4; bootstrap seeds fixed in the code.

## 5. Exploratory analyses
- **Recent Popularity** (`recent_popularity.py`): a material's score is the number of evaluated students who opened it in the last W days before the cutoff (W = 28 primary, fixed before running; 14 and 56 sensitivity). Ties are broken by overall training popularity. Only pre-cutoff clicks are used.
- **Recent Popularity + CF blend** (`blend_recent.py`): min-max normalized, CF weight 0.25 or 0.5.
- **Time-aware CF** (`time_aware_cf.py`): item-based CF with each interaction weighted by exp(-age/tau), tau = 28 days primary (14 and 56 sensitivity).
- **Type-only CBF and Hybrid** (in `pipeline.py`): added after seeing results.
- **Cohort check** (`recent_cohort_check.py`): the evaluated students were selected partly by activity after the cutoff, so this check rebuilds the contributor cohort from pre-cutoff information only (students with at least 10 materials before the cutoff). The conclusions did not change.

These analyses measure later use of course materials in an offline setting. They do not measure learning.
